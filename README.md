# An AI agent that does your interior design research for you.

## The Problem
Designing a room means hours of scrolling Pinterest, Reddit, and design blogs — collecting inspiration, comparing styles, and trying to figure out what you actually want. I didn't want to spend that time.

### What It Does
Tell the agent which room you're designing. It asks a few targeted questions — style preferences, constraints, what you're keeping — then goes off and finds curated design inspiration on your behalf, organised and ready to act on.

### How It Works
Built with a plan-then-execute approach using Claude Code:
The agent produces a research plan before doing anything
You review and approve the plan
It executes — searching, pulling references, and summarising findings by theme

This keeps the human in the loop without slowing things down.

Why This Approach
Separating planning from execution makes agent behaviour transparent and controllable — a pattern that matters in production AI systems. This project was a deliberate exercise in building agents that are useful and trustworthy.
