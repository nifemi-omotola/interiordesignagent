# Design Research Workflow

Use this workflow whenever the user gives you a design task or asks for design inspiration.

---

## Step 1 — Ask Clarifying Questions First

Before researching anything, ask these questions. Do not skip this step.

1. **What is being designed?** (e.g. a mobile app screen, logo, social media post, landing page, poster, packaging)
2. **Who is it for?** Describe the target audience — age range, interests, context (e.g. busy parents, Gen Z students, corporate professionals)
3. **What platform or medium?** (e.g. iOS app, website, Instagram post, print flyer)
4. **What mood or style are you going for?** (e.g. minimal and clean, bold and playful, warm and friendly, sleek and premium, earthy and natural)
5. **Any colours in mind?** Or any colours you want to avoid?
6. **Name 1–2 brands or designs you like** — these can be from any industry, not necessarily the same one
7. **Anything you want to avoid?** (competitor designs, styles, colours that feel wrong)

Wait for the user's answers before proceeding to Step 2.

---

## Step 2 — Research

Run web searches to gather strong design references. Search across these angles:

- **Trends**: e.g. "2024 [category] design trends", "[style] UI design inspiration [year]"
- **Competitors/peers**: e.g. "[industry] brand identity examples", "best designed [product type] apps"
- **Community picks**: Search terms that surface Dribbble, Behance, Awwwards, and Pinterest results (e.g. "Dribbble [keyword] UI", "Behance [keyword] branding")
- **Reference brands the user mentioned**: Search their examples directly to understand what specifically appeals to them

Collect at least 8–10 strong image or design references with source URLs.

---

## Step 3 — Organise and Save Output

Create a folder at `output/[task-slug]/` (use a short, lowercase, hyphenated name for the task, e.g. `output/meditation-app/`).

Save three files:

### File 1: `research-summary.md`
- What this design space looks like right now (trends, conventions, what's overdone)
- Who the key players / competitors are and what their design language says
- What makes the strong examples strong
- Cite all sources

### File 2: `image-references.md`
For each reference, include:
- **Title** — name or short description of the image/design
- **Source URL** — direct link
- **Why it's relevant** — one or two sentences on what makes it a good reference for this task
- **Tags** — style, colour, mood (e.g. `#minimal #warmtones #serif #editorial`)

Aim for 8–10 references minimum, grouped by theme if helpful.

### File 3: `recommendations.md`
- **Design direction** — 2–3 short paragraphs on the recommended visual approach
- **Colour palette ideas** — suggest 2 palette options with hex codes and a rationale for each
- **Typography suggestions** — 1–2 font pairing ideas and why they suit the brief
- **Do's** — 3–5 things to lean into
- **Don'ts** — 3–5 things to avoid

#### Next Steps
End the file with a clear "Next Steps" section — concrete, actionable recommendations such as:
- Which 3–5 image references to use as a starting mood board (and where to build it, e.g. Figma, Canva, Pinterest board)
- Which colour palette to try first and how to test it
- Whether to prototype quickly in Canva or commission a designer
- Any user testing or stakeholder input that should happen before committing to a direction
- A suggested order of operations for moving from inspiration to execution

---

## Rules to Follow

- Always ask clarifying questions before starting (Step 1 is mandatory)
- Cite every source — no uncited claims
- Keep writing concise and jargon-free
- Save all output files to the correct `output/[task-slug]/` folder
- Tag all image references with style, colour, and mood tags
